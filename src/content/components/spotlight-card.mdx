## Cursor-Following Spotlight Card

A flagship creative component popularized by modern design systems. Tracks cursor coordinates relative to the bounding box to render an elegant illumination cone without layout reflows.

## Performance Engineering

- **GPU Acceleration:** Uses CSS radial gradients driven by pointer coordinates without touching the DOM tree layout or causing browser re-paints.
- **Motion Template:** In the Animated variant, Framer Motion's `useMotionValue` and `useMotionTemplate` stream coordinates directly to the compositor thread for a solid 60/120 FPS experience.
- **Pointer Fallback:** On touch devices where hover is absent, the spotlight smoothly defaults to a soft static gradient overlay.
